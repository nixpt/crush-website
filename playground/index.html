Try Crush

This is the real Crush compiler and VM, compiled to WebAssembly. Nothing is sent to a server. A program here holds nothing beyond printing and the standard library until you grant it more below the editor: @javascript, @python, an in-memory filesystem, the clock. Asking for anything else is refused before the program runs, and the page shows you why. That refusal is the point of the language.

What runs here

                
Crush source is parsed, compiled to CASM bytecode and executed on the portable CVM interpreter, the same pipeline crush-run uses natively. Each run starts fresh and is capped at one million VM instructions. A granted @javascript block runs in a sandboxed worker with no network and no access to this page; @python runs in Pyodide, real CPython compiled to WebAssembly.

            

            

                
What doesn't, yet

                
A browser has no shell, processes or other interpreters to give, so @bash and the other polyglot languages, net and process can't be granted here. The fs grant is an empty in-memory directory, not your disk, and env is empty. Programs that read input with io.read pause and ask you for each line.

            

            

                
Run it natively

                
The toolchain is open source at nixpt/crush-ast. The language guide lives at docs.crushlang.org.
